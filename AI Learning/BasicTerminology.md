Token

✅ 为什么 Token 重要？
模型输入限制： LLM 对一次可以处理的 token 数是有限的，比如 GPT-4-turbo 支持最多 128k tokens。

训练和推理单位： 模型的训练、生成、推理过程，都是基于 token 运作的。

计费单位（商业模型）： 像 OpenAI、Anthropic 这类服务通常按 token 数计费。

语义处理粒度： Token 处理是模型理解语言的底层基础。

✅ Why are Tokens Important?

Model Input Limit: LLMs have a maximum number of tokens they can process in a single input. For example, GPT-4-turbo supports up to 128k tokens.

Unit of Training and Inference: The training, generation, and inference processes of the model are all based on tokens.

Billing Unit (Commercial Models): Services like OpenAI and Anthropic typically charge based on the number of tokens used.

Granularity of Semantic Processing: Tokenization is the foundational level at which the model understands and processes language.
